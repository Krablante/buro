# Overview

BURO makes agent context authoritative, typed, fast, and reviewable. RAG makes deterministic lookup probabilistic. Distributed `AGENTS.md` files create drifting authority. BURO replaces both with one registry and one command contract.

The database stores facts, the preset defines their finite shape, and rendered packets are disposable views. There is no stored packet text, indexing service, scanner, generated context tree, plugin model, or hidden processor chain.

The `starter` preset works on one machine or several. Politia uses the same public engine with the bundled `politia` preset across several hosts. Multihost adds only an HTTP transport; it does not change the data model.

Ordinary facts change through one local reviewed draft. Complete export/import exists only for portability, recovery, and deliberate whole-schema migration.
