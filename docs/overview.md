# Overview

BURO makes agent context authoritative, typed, fast, and reviewable. RAG makes deterministic lookup probabilistic. Distributed `AGENTS.md` files create drifting authority. BURO replaces both with one registry and one command contract.

The database stores facts, the preset defines their shape, and rendered packets are disposable views. There is no stored packet text, indexing service, scanner, generated context tree, plugin model, or hidden processor chain.

Politia uses BURO across several hosts, but the engine is equally complete on one machine. Multihost adds only an HTTP transport; it does not change the data model.
