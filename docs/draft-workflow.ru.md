# Изменение через черновик

[English](draft-workflow.md) · [Русский](draft-workflow.ru.md) · [README](../README.ru.md)

Один локальный YAML-черновик — обычный путь записи, независимо от того,
работает ли CLI с SQLite напрямую или с центральным API. Создание,
изменение и удаление выглядят так:

```text
buro draft new my-service service    # также: pull my-service / delete my-service
# Открой YAML-файл по пути, который напечатает команда.
buro draft diff
buro draft push
```

Если не указать тип при `new`, используется настроенный тип по умолчанию.
Существующие факты находятся в активных YAML-полях, недостающие обязательные
поля отмечены, а необязательные закомментированы с полной формой вложенной
записи. Пояснения помогают разместить факты правильно. Неизвестные факты
оставляй пустыми. Одновременно существует один черновик; `buro draft clear`
удаляет его по явному решению.

Внутренние данные `__buro` хранят тип операции и исходную версию. Id при
изменении остаётся прежним. `diff` сравнивает черновик с текущей записью и
отклоняет устаревшую версию; `push` проверяет запись, ссылки и уникальность,
снимает копию SQLite перед записью, применяет изменение и убирает черновик.
При неудаче черновик остаётся. Если другой оператор успел поменять запись,
получи свежий черновик и проверь правку снова. Большой черновик можно
сравнить без квадратичного расхода памяти; почти полностью переписанный
участок иногда показывается как удалённые и добавленные строки.

Заполняйте только известные полезные поля. Запись с именем и одним правилом
допустима. Для стандартного пути без host подставляется текущая машина клиента;
это значение видно в diff до сохранения. Не удаляйте посторонний черновик ради
новой задачи. До изменения типов завершите или явно сохраните активный draft.

Путь по умолчанию — `<instance_root>/BURO_DRAFT.yaml`. Его меняют
`draft_path` или `BURO_DRAFT_PATH`. На клиенте черновик остаётся локальным:
на сервер отправляется проверенный JSON сущности с исходной версией. Второго
черновика на сервере нет. Подробнее об API — в
[«Интерфейсах»](interfaces.ru.md).
