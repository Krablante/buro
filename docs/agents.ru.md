# Подключение агента

[English](agents.md) · [Русский](agents.ru.md) · [README](../README.ru.md)

Выполните `buro init`, затем `buro connect <client>`. Агенту нужен терминал.
BURO не читает историю чата и не запускает модель: сведения из разговора
использует ваш агент. Он поддерживает устойчивые факты, когда вы разрешили
это делать. Само подключение не даёт безусловного разрешения на запись и не
изменяет остальные полномочия агента.

| Клиент | Установка |
| --- | --- |
| OpenCodez | `~/.config/opencodez/plugins/buro.js` и `skills/buro/SKILL.md` |
| OpenCode | `~/.config/opencode/plugins/buro.js` и `skills/buro/SKILL.md` |
| Codex | Блок в `~/.codex/AGENTS.md` и `~/.agents/skills/buro/SKILL.md` |
| Claude Code | Блок в `~/.claude/CLAUDE.md` и `skills/buro/SKILL.md` |
| Другой агент | `buro connect file --path <instruction-file>` добавляет блок инструкций |

Для именованного клиента `--path <directory>` выбирает другой каталог профиля.
Для отдельного профиля Codex skill попадает в его `skills/`; по умолчанию
используется пользовательский `.agents/skills`. Убедитесь, что выбранный
профиль и skills действительно обнаруживаются вашим клиентом.

Плагины OpenCode обнаруживаются автоматически: править JSONC не требуется.
После установки перезапустите OpenCode/OpenCodez; в остальных клиентах начните
новую сессию. Плагин кэширует инструкции, а не факты реестра. Недоступность BURO
не мешает начать разговор.

Повторное подключение допустимо. Блок сохраняет окружающий текст. Управляемые
файлы заменяют только файлы, помеченные BURO; изменённый файл сохраняется в
резервной копии рядом. Посторонний файл по управляемому пути останавливает
установку. После обновления BURO подключитесь снова, чтобы обновить skill и
плагин. Файлы не попадают в исходники проекта без явно выбранного пути.

`buro agent` выдаёт короткий блок для System prompt, `buro agent --full` —
подробные правила, поставляемые в skill. Они не зависят от типов и папок.
Свои типы объясняют поля через guides.

Подключение можно проверить без вызова модели: прочитать установленные файлы,
выполнить `buro agent` и получить известную запись из того же окружения,
где работает агент. Для проверки поведения попросите агента получить объект,
сохранить разрешённое устойчивое правило и использовать его в новой сессии.
Успешная установка файлов не гарантирует соблюдения правил моделью.

Для клиентов без терминала нужен другой транспорт инструментов. В этом релизе
есть CLI и HTTP; MCP-сервер не поставляется. Сам HTTP не устанавливает правила.
