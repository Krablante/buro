# Подключение агентов

[English](agents.md) · [Русский](agents.ru.md) · [README](../README.ru.md)

Агенту нужны доступ к `buro` в терминале и инструкция, когда обращаться к памяти.
Готовый skill объясняет поиск и проверяемое обновление записей.
[Блок для системного промпта](../integrations/system-prompt.md) можно скопировать
вручную. BURO не выбирает и не переписывает ваш системный промпт.

## Готовые подключения

| Цель | Файлы в стандартном профиле | Контекст сессии |
| --- | --- | --- |
| opencodez | ~/.config/opencodez/skills/buro/SKILL.md; plugins/buro.js | Плагин system transform |
| opencode | ~/.config/opencode/skills/buro/SKILL.md; plugins/buro.js | Плагин system transform |
| codex | ~/.agents/skills/buro/SKILL.md; ~/.codex/hooks/buro-session-start.cjs; hooks.json | Командный hook SessionStart |
| claude | ~/.claude/skills/buro/SKILL.md; hooks/buro-session-start.cjs; settings.json | Командный hook SessionStart |

Запустите `buro connect <цель>`. Для OpenCode/OpenCodez профиль выбирается через
`OPENCODE_CONFIG_DIR`, если переменная задана; `--path <профиль>` имеет приоритет.
При явном выборе профиля skill устанавливается в его skills. Чужие hooks и настройки
сохраняются. Перед изменением файла создаётся копия; неизменившиеся подключения
не перезаписываются. Конфликт с чужим skill или плагином сообщается явно.
При переподключении Codex или Claude удаляется прежний управляемый блок
инструкций BURO; остальной текст остаётся.

OpenCode и OpenCodez загружают плагин при запуске, поэтому нужен перезапуск.
Плагин использует `experimental.chat.system.transform`, запускает current
один раз на сессию, объединяет одновременные первые запросы и повторно использует
результат в следующих обращениях к модели. Удаление сессии освобождает её кэш.
Передаются только сведения current; контракт агента и все определения не вставляются.

Локальный Codex должен поддерживать hooks.json, SessionStart и
`hookSpecificOutput.additionalContext`. Формат текущих версий описан
[в документации Codex](https://developers.openai.com/codex/hooks). Через `/hooks`
проверьте и разрешите установленный hook, включите hooks, если они отключены,
затем начните новую сессию. Разрешение контролирует сам Codex; connect его
не обходит. Claude Code должен поддерживать командный SessionStart и
additionalContext; см. [документацию Claude](https://code.claude.com/docs/en/hooks).
Общий обработчик — CommonJS-файл Node без сторонних зависимостей.

SessionStart срабатывает на startup или clear. Продолжение сессии использует
её прежний контекст; сжатие не запускает загрузку заново. При необходимости
обновите сведения командой `buro current`. Эти подключения рассчитаны на местные
терминальные харнессы; облачные сессии Codex они не настраивают.

Команда ограничена восемью секундами. Отсутствующий CLI, тайм-аут, недоступный
сервер или неверный вывод current даёт видимое сообщение об ошибке загрузки
памяти, но не мешает разговору. Полная запись устройства может содержать всё,
что в неё сохранили, включая секреты. Учитывайте это при автоматической загрузке;
список объектов ограничивается current_limit.

## Другие агенты

```sh
buro connect file --path /path/to/AGENTS.md
```

Эта явная команда поддерживает помеченный блок инструкций в выбранном файле.
Плагин и автоматический current не устанавливаются. Можно также скопировать
готовый промпт или skill и настроить запуск средствами самого харнесса.
Перед работой с устройством агент должен получить current, если его ещё нет.

После обновления BURO повторите connect и перезапустите OpenCode/OpenCodez.
Плагин и обработчик hooks входят в тот же выпуск BURO; отдельно обновлять
репозиторий или пакет плагина не требуется.
